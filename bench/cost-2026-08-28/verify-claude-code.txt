# Todo API

A small REST API for todos, built with Node, TypeScript and Express. Todos are kept in
memory only, so all data is lost when the process stops.

## Requirements

- Node.js 20 or newer (uses the built-in `node:test` runner and global `fetch`)
- npm

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

The server compiles the TypeScript sources and listens on <http://localhost:3000>.
Set the `PORT` environment variable to use a different port.

## Test

```bash
npm test
```

This type-checks and compiles the project, then runs the test suite against a real HTTP
server on an ephemeral port.

## Other scripts

- `npm run build` - compile TypeScript to `dist/`
- `npm run typecheck` - type-check without emitting files

## Data model

| Field       | Type    | Notes                                         |
| ----------- | ------- | --------------------------------------------- |
| `id`        | string  | UUID, generated by the server                 |
| `title`     | string  | Required, non-empty, max 200 characters       |
| `completed` | boolean | Defaults to `false`                           |
| `createdAt` | string  | ISO 8601 timestamp, set at creation           |

Titles are trimmed before being stored, and the length limit applies to the trimmed value.

## Endpoints

| Method   | Path         | Description                                |
| -------- | ------------ | ------------------------------------------ |
| `POST`   | `/todos`     | Create a todo                              |
| `GET`    | `/todos`     | List todos, optionally filtered            |
| `GET`    | `/todos/:id` | Fetch a single todo                        |
| `PATCH`  | `/todos/:id` | Update a todo's title and/or completed flag |
| `DELETE` | `/todos/:id` | Delete a todo                              |
