# Todo API

Small in-memory todo REST API built with Node, TypeScript, and Express.

## Setup

```
npm install
```

```
npm start
```

Compiles the TypeScript sources and starts the server on `http://localhost:3000`.

## Test

```
npm test
```

Runs the Jest test suite (uses supertest against the Express app in-process).
