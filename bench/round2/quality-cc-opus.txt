# Todo API

A small REST API for managing todos, built with Node, TypeScript and Express.
Todos are held in memory only: all data is lost when the process stops.

## Requirements

- Node.js 20 or newer (uses the built-in `node:test` runner and `crypto.randomUUID`)
- npm

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

The server listens on port 3000 (`http://localhost:3000`). Set the `PORT`
environment variable to use a different port.
